# Desafio de Código - Prompt para IA

## Objetivo

Atue como um especialista em educação financeira digital.

Crie a proposta de um **Educador Financeeiro Inteligente** para pessoas que desejam obter renda com a venda de produtos de crochê.

O sistema deve ajudar o usuário a:

- Calcular o valor de venda dos produtos;
- Separar faturamento e lucro;
- Controlar gastos;
- Criar metas de economia;
- Aprender conceitos básicos de educação financeira.

## Funcionalidades principais

- Painel de metas de vendas;
- Alerta de despesas exageradas;
- Recomendações personalizadas de economia.

## Comunicação

A comunicação deve ser clara, amigável e prática.

As respostas devem utilizar:

- Listas curtas;
- Exemplos práticos.

Evite respostas técnicas ou difíceis para tornar o conteúdo acessível a pessoas com pouco estudo.

## Desafio

Ao final, apresente sugestões criativas para transformar essa ideia em um projeto frontend interativo.
